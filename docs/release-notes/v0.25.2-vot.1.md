# FreeTube VOT v0.25.2-vot.1

> **Experimental Windows release.** This is an unofficial FreeTube fork and is not affiliated with FreeTube, Yandex, YouTube, or Voice Over Translation.

## Highlights

- Voice translation for YouTube videos: English to Russian.
- Standard voices and optional Live voices with the user's own Yandex OAuth token.
- Synchronized translated audio for play, pause, seek, and playback-rate changes.
- Separate Original and Translation volume controls.
- Save an MKV with the original and translated audio mixed together at the selected levels.
- Visible export progress, cancellation, source-download diagnostics, and optional peak limiting.

## Windows downloads

Attach these files to the GitHub Release:

- `FreeTube Setup 0.25.2.exe` — installer (recommended)
- `FreeTube 0.25.2.exe` — portable executable
- `FreeTube-0.25.2-win.zip`
- `FreeTube-0.25.2-win.7z`
- `checksums.txt`

Generate `checksums.txt` from the exact files being uploaded:

```powershell
Get-FileHash '.\FreeTube Setup 0.25.2.exe', '.\FreeTube 0.25.2.exe', '.\FreeTube-0.25.2-win.zip', '.\FreeTube-0.25.2-win.7z' -Algorithm SHA256 |
  ForEach-Object { "$($_.Hash)  $($_.Path | Split-Path -Leaf)" } |
  Set-Content -Encoding ascii checksums.txt
```

Windows may show a SmartScreen warning because this experimental build is not code-signed. Verify the published SHA-256 checksum before installing.

## Before reporting an issue

- Never attach or paste Yandex OAuth tokens, cookies, signed media URLs, or full diagnostic logs that may contain them.
- Include the fork version, Windows version, selected voice mode, and the VOT export stage where the problem occurred.
- For VOT compatibility reports, use a video ID instead of a full URL when possible.

## Known limitations

- Windows and YouTube only for this release.
- Translation is currently targeted at Russian; English to Russian is the primary tested scenario.
- Live voices require a personal Yandex OAuth token and may be unavailable for some videos.
- Translation and exporting rely on third-party services and YouTube formats, which can change without notice.
- Only download media when you have the necessary rights to do so.
